# Bundled fonts

Only the digits 0-9 of each face are compiled into the app (see the
`characterRegex` on each resource in package.json), so the whole set costs a
few kilobytes.

| Face | File | Licence |
|---|---|---|
| Ubuntu Bold | `Ubuntu-B.ttf` | Ubuntu Font Licence 1.0 |
| Source Serif 4 Display Bold | `SourceSerif4Display-Bold.otf` | SIL Open Font License 1.1 |
| Ubuntu Condensed | `Ubuntu-C.ttf` | Ubuntu Font Licence 1.0 |
| Hack Bold | `Hack-Bold.ttf` | MIT (with Bitstream Vera licence for the derived outlines) |

All three permit embedding and redistribution. The licence texts ship with the
upstream font packages.
